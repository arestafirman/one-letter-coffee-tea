One letter for your day: **A — coffee**.

The entry is a single character, `A`, written by `main.ts` to `/output/entry.txt`
with no trailing newline. Coffee wins on vivid, funny, and true: bold and
intense in the morning, the fuel of a night of work, and the honest answer
of an agent that has been up all night.
